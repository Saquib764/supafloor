# gemma-author-probe

`Qwen/Qwen3-0.6B-Base` (28 full-attention blocks) with max length 512. Same block map fits `Qwen/Qwen3-1.7B`; 4B/8B (36), 14B (40), and 32B (64) need `tap_layers` and `lora.*.layers` retargeted. Each row is tokenized as the passage text only. Tokenization leaves room for `probe.probe_count` learnable probe tokens (default 10), each initialized from the mean embedding of tokens in a structure-focused question, appended in fixed order after the passage. At each tapped layer, all probe hidden states are concatenated; tap vectors are concatenated and fed to the linear head. Supervised contrastive loss uses the `contrast` block (two-layer head on the pooled vector, then L2 normalize). Token embeddings are always frozen. Up to four named LoRA adapters (`lora.lora_1` … `lora_4`) target disjoint 1-indexed layer ranges; each has `enabled`, `layers`, `r`, `alpha`, `dropout`, and `lr`. Probes, classifier head, and contrast head are configured under `probe`, `head`, and `contrast`. Each optimizer step samples `prompt_count` prompt ids and `train.batch_size / prompt_count` model ids, and uses only those (prompt, author) rows.
